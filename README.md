📥 Установка из гарнитуры: прямо в шлеме (без ПК)

1️⃣ Скачайте APK-файл
 🌐 Откройте стандартный браузер внутри Quest 3, 3s ...
 🔗 Перейдите на GitHub-страницу нужного репозитория — QuackLauncher
 📂 Справа на странице найдите раздел Releases
 ⬇️ Откройте последнюю версию
 📱 Нажмите на файл с расширением .apk, чтобы скачать его во внутреннюю память шлема

2️⃣ Установите файловый менеджер, если его ещё нет
 🛍️ Откройте Meta Store прямо в шлеме
 🔎 Найдите бесплатный файловый менеджер, например AnExplorer VR
 ✅ Установите его

3️⃣ Запустите установку
 📁 Откройте файловый менеджер в шлеме
 ⬇️ Перейдите в папку Downloads / Загрузки
 📦 Нажмите на скачанный .apk-файл
 🔐 Если система попросит разрешить установку из этого источника — разрешите
 🛠️ Нажмите Установить

4️⃣ Готово
 🎉 После установки приложение появится в библиотеке или в разделе со сторонними приложениями
 🚀 Запускайте и пользуйтесь

⚠️ Если установка не начинается:
• проверьте, что APK-файл скачался полностью
• разрешите установку из неизвестных источников для файлового менеджера
• попробуйте открыть APK ещё раз через файловый менеджер
