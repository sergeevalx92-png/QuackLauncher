# QuackLauncher

Установка из гарнитуры: прямая установка через шлем (Без ПК)

1. Скачайте APK-файл:
	• Откройте стандартный браузер внутри Quest 3.
	• Перейдите по ссылке на нужный репозиторий GitHub - QuackLaucnher.
	• Откройте раздел Releases (Релизы) с правой стороны страницы.
	• Найдите последнюю версию и кликните по файлу с расширением .apk, чтобы скачать его во внутреннюю память шлема.
2. Откройте файловый менеджер - Файлы (или установите если еще не установлен):
	• Зайдите в официальный Meta Store прямо в шлеме.
	• Найдите и скачайте бесплатный файловый менеджер (например, AnExplorer VR).
3. Запустите установку:
	• Откройте скачанный файловый менеджер в шлеме.
	• Перейдите в папку Downloads (Загрузки).
	• Кликните по скачанному с GitHub APK-файлу.
	• Если система попросит разрешить установку из этого источника, подтвердите действие и нажмите Установить.
